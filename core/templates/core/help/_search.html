Search

RidgeNote gives you several ways to find notes, each suited to a different situation. The important difference between them is not only where you search, but also what each tool searches.

Filter in the folder tree

The Filter notes field above the folder tree narrows the folders and notes currently shown in the tree as you type.

What it searches:

  • Folder names
  • Note titles

It does not search the contents of your notes.

This is useful when you're already browsing the tree and simply want to reduce a long list. It does not perform the same kind of full-library search as Search or Full Search.

Recent notes / Quick Switch

The Recent notes button on an open note shows notes you've viewed recently.

What it searches:

  • Note titles
  • Folder names

The search is limited to the notes already in your Recent notes list; it does not search your entire library or note contents.

This makes it a fast way to jump back to something you were working with recently without performing a broader search.

Search

Select Search in the top bar for a quick search across your library.

What it searches:

  • Note titles
  • Note contents

It does not search folder names or tags.

This search is designed for quickly finding a note by its title or by a distinctive word or phrase inside it. If you need to combine several filters at once, use Full Search instead.

Full Search

Open Full Search from the account menu when you need the most complete search and filtering options.

What its text search searches:

  • Note titles
  • Note contents

You can then combine that text search with additional filters:

  • Select one or more tags and choose whether notes must match Any or All of them. See Tags.
  • Tag status to show only notes that have tags or only notes without tags.
  • Limit results to a particular Folder, including Unfiled. See Folders.
  • Turn on Include Trash when you also want to search notes currently in Trash. See Trash and Recovery.

Your active filters appear as removable chips so you can see exactly what is narrowing the results and remove individual criteria without starting over.

Full Search stores its current filters in the page's URL, so a useful search can be bookmarked or returned to later.

Large result sets are divided into multiple pages.

Which one should I use?

As a general rule:

  • Use the folder-tree Filter when you remember a folder name or note title and are already browsing the tree.
  • Use Recent notes when you remember a note title or folder name and know you've viewed the note recently.
  • Use Search when you remember a note title or a distinctive word inside the note and want to search your whole library quickly.
  • Use Full Search when you need to search note titles or note contents, or narrow results using tags, folders, or Trash.
