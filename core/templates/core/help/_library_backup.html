Library Backup and Restore

RidgeNote lets you download a portable backup of your library and restore it later if needed.

A Library Backup is intended to protect the information stored inside RidgeNote -- your notes, folders, tags, and the relationships between them. It can also be used to move a library to a different RidgeNote account or another RidgeNote installation.

A Library Backup is separate from your RidgeNote account itself. Your username, password, role, and personal Preferences are not part of the library backup.

Downloading a Library Backup

Open the account menu or the Account page and select Download library backup.

RidgeNote creates a backup ZIP file containing your current library and downloads it to your computer. The ZIP also contains readable text copies of your notes.

Library Backups are useful for:

  • keeping an independent copy of your notes and library;
  • recovering your library if something goes wrong;
  • moving your library to another RidgeNote account;
  • moving your library to another RidgeNote installation.

It is a good idea to download a fresh Library Backup periodically, and especially before making large or potentially destructive changes to your library.

Restoring a Library Backup

Open the Account page and select Restore previous library backup.

Choose the RidgeNote Library Backup file you want to restore. RidgeNote shows you a preview before anything is changed and requires an explicit confirmation before the restore proceeds.

A Library Restore is a destructive process: it replaces your current library. It does not merge the backup with what is already there.

That means the notes, folders, and tags currently in the account are replaced by the library contained in the backup.

If you need to keep anything that is currently in the account, download a separate Library Backup first and/or download individual notes you want to preserve before starting the restore.

Because Restore is a replacement rather than a merge, RidgeNote does not need to resolve individual note-title, folder-name, or tag-name collisions with the existing library.

For this reason, make sure you are restoring the correct backup before confirming the operation.

Restoring to a different account

A Library Backup is not permanently tied to the account that originally created it.

If you restore a backup while signed in to a different RidgeNote account, the restored library becomes the library of the account performing the restore.

The account that originally created the backup is not changed.

This makes Library Backup useful for moving a note library between accounts as well as for ordinary recovery.

After the restore completes, you can download a new Library Backup from the restored account in the usual way.

What a Library Backup does not include

A Library Backup contains your RidgeNote library -- your folders, notes, tags, and their relationships -- not your account identity or server configuration.

It does not restore:

  • your username or account identity;
  • your password or login credentials;
  • your RidgeNote role;
  • your personal Preferences;
  • server or deployment configuration.

The account receiving the restore keeps its own identity, permissions, and Preferences while receiving the library from the backup.

See Account and Preferences for more about account-level settings.

Backup and Trash serve different purposes

Trash and Recovery protects you from accidental deletion for a limited period of time.

A Library Backup gives you an independent copy of your library that you control outside RidgeNote.

For information that is especially important to you, it is best not to rely on Trash alone.

See Trash and Recovery for more about RidgeNote's built-in recovery periods.
