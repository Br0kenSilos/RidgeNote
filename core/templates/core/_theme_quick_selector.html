{% comment %} A directly visible, compact top-bar theme control -- the account menu's own copy (still present in the narrow drawer as its narrow fallback, see `notes/_nav_drawer.html`) no longer duplicates this at the header level. Shared between `base.html`'s default header and `notes/detail.html`'s workspace header (never rendered by both at once, since one always overrides the other's `app_header` block) so the two never drift apart. Reuses `.account-menu`'s own `
` popover mechanics verbatim -- `initAccountMenus()` (app.ts) already targets every `.account-menu` generically, so this control's own outside-click/Escape-to-close behavior needs no new JS at all, only this markup. Uses `sun.svg` rather than `contrast.svg` (both already-vendored Lucide icons, same sourcing convention -- `sun.svg` was unused elsewhere in the app). At the actual compact top-bar size, `contrast`'s circle-plus-inner-arc read as an ambiguous dot rather than anything theme-related; `sun`'s distinct rayed-circle shape stays legible that small and is the icon most commonly recognized as an appearance/display control. `moon` was considered and rejected here specifically because a single crescent reads as a binary light/dark toggle, which would misrepresent this control -- selecting from a named list of themes, not flipping one state, is still the actual interaction (unchanged from the reasoning that originally picked `contrast`). Trigger behavior, tooltip, and accessible label are unchanged. {% endcomment %}
