Tags

Tags give you another way to organize and find notes without changing where those notes live. Unlike folders, tags are not part of a hierarchy -- a note can have multiple tags, and the same tag can be used on notes in many different folders.

For example, you might use tags such as PROJECT, REFERENCE, IMPORTANT, or TODO to group related notes regardless of where they are stored.

Adding and removing tags

You can add or remove tags directly from an open note.

When adding a tag, you can select one that already exists or create a new one as you need it. Once a tag has been created, it becomes available for use on other notes as well.

Removing a tag from a note does not delete the tag itself or remove it from any other notes.

Tag Manager

Open Tag manager from the account menu to manage the tags in your library.

From Tag Manager you can:

  • Add tag to create a new tag and choose its color.
  • Rename a tag. The new name is reflected everywhere that tag is used.
  • Recolor a tag. The new color is reflected everywhere that tag appears.
  • Delete a tag, which removes it from every note currently using it.
  • Select multiple tags and use Delete selected to remove several tags at once.

Deleting a tag does not delete any notes. It only removes that tag from the notes where it was assigned.

Tag colors and Preferences

RidgeNote includes several tag colors to make tags easier to distinguish visually.

Under Preferences, you can control how new tags are created:

  • Uppercase tag names automatically stores newly created or renamed tag names in uppercase.
  • Use semantic tag colors allows certain commonly recognized tag names to automatically receive a matching color when they are created. For example, creating a tag named RED automatically gives that tag the red color.
  • Default color determines which color is used for a new tag when no other color has been explicitly chosen or automatically selected.

These preferences affect how tags are created or renamed; changing them does not automatically recolor or otherwise modify tags that already exist.

See Account and Preferences for more information about your personal settings.

Finding notes by tag

Tags become especially useful when combined with Full Search.

You can search for notes containing selected tags and choose whether a note must match Any or All of them. You can also limit results to notes that have tags or to notes that have no tags at all.

See Search for more about using tags and other filters together.
