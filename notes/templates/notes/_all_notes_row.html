{% comment %} One narrow reusable row partial for the All Notes list surface, built against the `.note-list__*` CSS that already existed for it (unused since the underlying markup was deleted when Home stopped rendering a full list). Reuses the same `row-action-menu`/`.tree-nav__row-menu-*`/ `.tree-nav__popover-form*` menu foundation already proven by the tree and note-detail's own overflow menu -- no new JavaScript is needed. Also included directly by Home's Recent Notes list, which gets the exact same Pin/Move/overflow-menu controls, not a lookalike or a stripped-down copy. `row_context` selects which already-existing, already-tested route each action posts to -- "all_notes" (default) targets the dedicated `_all_notes` views (which read `page`/`sort` to return to the same page/sort); "home" targets the routes the tree's own per-row menu already uses in Home context (`note_pin_set`, `note_move_home`, `note_rename_home`, and the bare `note_delete` with `data-delete-origin="home"`), every one of which already redirects to `home` on its own -- no new route, view, or Home-specific action logic was added anywhere. Named `row_context`, not `context`, because `{% include ... with context=... %}` collides with Django's own internal `context` render kwarg (`ContextDict.__init__() got multiple values for argument 'context'`). Expects `note` in the template context always; `page`/`sort`/`folders` only meaningful (and only rendered into hidden inputs) when `row_context` is "all_notes". {% endcomment %}
