Folders

Folders give your notes a simple one-level structure. RidgeNote does not support folders nested inside other folders, which keeps the library easy to browse and avoids deeply buried notes. I may consider adding nested folder levels in a future release, but for now that felt counter to the idea of keeping RidgeNote simple.

A note that is not inside a folder appears under Unfiled.

Creating and organizing folders

Use New folder from the folder tree to create a folder.

Once a folder exists, you can:

  • Rename it.
  • Move notes into it.
  • Move notes back to Unfiled.
  • Use the tree's Filter field to narrow the folders and notes currently shown.

See Notes for more about moving and organizing individual notes.

Moving a folder to Trash

Moving a folder to Trash also moves the active notes inside that folder to Trash at the same time.

If you restore the folder later, RidgeNote restores the notes that were moved to Trash with it, as long as each note is still eligible for recovery.

Notes that were already moved out of the folder before it was trashed are not affected. Notes that had already been trashed separately are also handled independently.

See Trash and Recovery for the recovery periods and what happens after items leave your own Trash.
