Trash and Recovery

Moving a note or folder to Trash does not immediately delete it. RidgeNote keeps deleted items recoverable for a period of time so you have a chance to change your mind.

Your Trash

Open View My Trash from the account menu to see the notes and folders you have deleted.

For the first 30 days after deletion, an item remains visible in your Trash and you can restore it yourself.

Select Restore to return the item to your library.

If you restore a folder, RidgeNote also restores the notes that were moved to Trash with that folder, as long as each note is still eligible for recovery. See Folders for more about folder Trash behavior.

Restore conflicts

Restoring a note normally does not create a naming conflict. RidgeNote allows more than one note to have the same title.

If a note's original folder is still available, the note is restored there. If that folder has since been moved to Trash, RidgeNote restores the note into your Recovered Items folder instead and tells you what happened.

Folder restores work a little differently because active folder names must be unique.

For example, suppose you move a folder named PROJECTS to Trash and later create a new active folder named PROJECTS. If you try to restore the original folder, RidgeNote will not overwrite the newer folder, merge the two, or silently rename either one.

Instead, the restore is stopped and RidgeNote tells you that an active folder with that name already exists. The original folder remains safely in Trash until the conflict is resolved.

Folder-name matching is not case-sensitive, so PROJECTS and Projects are considered the same name for this purpose.

Empty Trash

Empty Trash immediately removes the items from your own Trash view.

It does not permanently delete them at that moment.

Instead, those items move directly into RidgeNote's administrator-recovery stage, where they can still be recovered by an administrator until the final recovery period expires.

Use Empty Trash when you no longer want deleted items appearing in your own Trash but still want RidgeNote's recovery protection to remain in place.

Administrator Recovery

After an item leaves your own Trash -- either because 30 days have passed or because you used Empty Trash -- you can no longer restore it yourself.

The item remains available through Administrator Recovery until 90 days after its original deletion date.

If you need something restored during this period, contact a RidgeNote administrator.

When requesting a restore, provide as much information as you remember about the item, such as its title, approximate deletion date, or the folder it came from. This helps the administrator identify the correct item.

Items restored for you by an administrator may be returned to their original folder when possible. If a note's original folder is no longer available, RidgeNote places it in a Recovered Items folder instead.

Privacy note: Administrators cannot read the contents of your deleted notes through Administrator Recovery. They can see limited identifying information, such as the note title and deletion date, so they can locate and restore the item you request. This is another reason a descriptive title can be helpful when asking for a recovery.

Final purge

Once an item reaches 90 days from its original deletion date, RidgeNote permanently removes it from the Trash and Administrator Recovery system.

After that point, it can no longer be restored through RidgeNote's recovery tools.

Because Trash is intended primarily to protect against accidental deletion -- not to serve as your only backup -- you should also keep periodic Library Backups of information you do not want to lose.

See Library Backup and Restore for more information.
