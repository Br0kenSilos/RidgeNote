Notes

Notes are the heart of RidgeNote. You can create them quickly, format their contents, organize them with folders and tags, and download or print them whenever you need a copy outside RidgeNote.

Creating and editing notes

Select New note from the folder tree to create a note and start writing.

RidgeNote saves your changes automatically as you work. An open note also includes a Save button if you want to save immediately rather than waiting for the next automatic save.

If you try to leave a note while a change has not been saved yet, RidgeNote asks you to confirm before leaving so you don't accidentally lose your work.

Formatting

Select Show formatting on an open note to display the rich-text formatting controls. These include headings, bold, italics, lists, and links.

Web addresses that you type or paste into a note can become clickable links automatically.

Undo and Redo are also available while editing so you can reverse or restore recent changes.

Organizing a note

Several actions are available for keeping notes organized:

  • Rename changes the note's title.
  • Move places the note in another folder or moves it to Unfiled.
  • Duplicate creates a separate copy of the note.
  • Pin keeps an important note near the top of Home and All Notes for easier access.

You can also assign tags directly to a note or remove tags you no longer need. See Tags for more about creating and managing tags.

Notes can live inside a folder or remain Unfiled. See Folders for more about organizing your library.

Printing and downloading

Open More note actions for options that let you use a note outside RidgeNote:

  • Print opens the note in a printable form.
  • Export JSON downloads a structured copy of the note's content.
  • Download saves the note as plain text.
  • Download Markdown saves a Markdown version of the note.
  • Open in new tab opens the same note in a separate browser tab.

Finding a note again

Recent notes lets you quickly return to notes you've viewed recently.

For broader searching and filtering across your library, see Search.

Moving a note to Trash

When you no longer need a note, you can move it to Trash. Moving a note to Trash does not immediately delete it permanently, and you have time to restore it if you change your mind.

See Trash and Recovery for the recovery periods, Empty Trash, and what happens before an item is permanently removed.
